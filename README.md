# To-Do-List-App-with-Priority-Due-Dates-and-Categories
This is a modern and interactive To-Do List application built using React.js. It allows users to manage tasks with features like priority levels (represented with stars), due dates, search functionality, and task categories.

Features

Priority Levels: Tasks can be assigned a priority level using stars (1-3 stars). Each star represents a different priority (low, medium, high).

Due Dates: Set a due date for each task to keep track of deadlines.

Search Functionality: Filter tasks by text input to quickly find specific tasks.

Task Categories: Organize tasks into categories for better management.

Theme Toggle: Toggle between light and dark modes to enhance the user experience.

Responsive Design: The app is mobile-friendly and adjusts its layout to fit different screen sizes.

Technologies Used

React.js: For building the front-end interface and managing the state of the app.

CSS: For styling, with a focus on making the app look clean, modern, and user-friendly.

JavaScript: For handling app logic, such as adding, editing, deleting tasks, and managing the theme.
